## 真实设备和云端边界

本次发布验证仅使用离线模拟器 / 假传输，没有下发真实温度、水泵、启停指令，也未更改设备 MQTT 配置。

早先用户授权的小幅实机测试观察到温度和水泵目标的回报，后续用户反馈实机与云端温度回报存在差异；其原因没有确认。当前版本因此分别显示本机目标和云端回报，不把本机目标当作可信硬件实时值。

一秒内完成指离线模拟回读与界面验证，**没有承诺真实云端或设备一秒内执行**。协议缺少设备签名和指令关联 ID；已回读只表示观察到一致字段。

云端共享认证、服务器 ACL 和长期散热表现未修改或验证。本地加固无法阻止第三方绕过面板直接使用云端 MQTT；详见 [安全边界](安全边界.md)。
